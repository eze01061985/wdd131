Indie Game Starter

Website Plan

Jose Ezequiel Flores Menendez | WDD 131

Site Name

The name of my website is Indie Game Starter. I chose this name because the website will help beginners take their first steps in creating small indie games.

The site will use a simple text logo with the name Indie Game Starter, as shown at the top of this document.

Site Purpose

The website will introduce indie game development to people who want to make their first small game. It will explain how small games are created, introduce tools and game engines, and describe the basic development process. It will also include simple examples, beginner tips, and common challenges such as keeping a project small, finding time, and fixing bugs.

Why I Chose This Subject

I am a software developer and I have always been interested in video games. Recently, I started experimenting with creating small games. I enjoy combining programming with creativity, so I want to learn more about this topic while building the website.

Planned Pages

  • Home: An introduction to indie game development, common challenges, and small project ideas such as a maze game or a simple platformer.
  • Tools: An introduction to game engines and tools for programming, art, and sound. Visitors will be able to filter the tools by category and save favorites.
  • Getting Started: The steps from choosing an idea to building, testing, and sharing a small game. A form will let visitors enter a game idea and choose a project type to create a simple starting plan.

I will use an array of tool objects to create the tool cards. JavaScript functions will display the cards, filter them, and respond to the form. I will use conditions to show tips based on the selected project type and localStorage to remember favorite tools. Images will be optimized and use lazy loading where appropriate. A references page linked in the footer will list the sources for images and information.

Scenarios

  • What tools or game engines can I use to create my first small game?
  • What steps should I follow to turn a game idea into a playable project?
  • What common challenges do indie developers face, and how can I keep my first project manageable?

Color Schema

I chose dark blue and purple for a simple style that fits a website about games and programming. These colors are also used in this plan.

  • Dark blue (#24324A): Header, footer, headings, and buttons. Text on blue will be white.
  • Purple (#653A91): Links and small accents.
  • Light gray (#F4F5F8): Page background.
  • Dark gray (#292929): Paragraphs and lists.

Typography

Verdana: Headings and site name

Arial: Paragraphs, navigation, lists, and form labels. This sentence is an example of the body font.

These fonts are easy to read and do not require a separate font download.
